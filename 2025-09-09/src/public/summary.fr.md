Inertia relie un backend et un frontend moderne sans imposer la création d'une API JSON séparée. Cette présentation montre son fonctionnement dans Laravel, où les routes renvoient des pages Inertia rendues par Vue.

Les exemples utilisent les composants `Form` et `Link` pour éviter les rechargements complets, gérer les erreurs de validation et naviguer en conservant le routeur du serveur.
