# @soubiran/talks

TypeScript types and a Zod schema for the localized JSON files generated by [talks.soubiran.dev](https://talks.soubiran.dev).

`LocalizedTalkMetadata` describes one `meta.en.json` or `meta.fr.json` file. `LocalizedTalkCatalog` describes the matching `talks.en.json` or `talks.fr.json` catalog. `TalksStatisticsData` describes the statistics used by the talks site.

## Usage

Import `LocalizedTalkMetadata` for a per-talk metadata file, `LocalizedTalkCatalog` for a localized catalog, or `TalksStatisticsData` for site statistics. Pass `en` or `fr` as the type parameter when the locale is known. Use `talkMetadataSchema` or `talksStatisticsDataSchema` to validate JSON at runtime.
