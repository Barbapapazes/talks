# @soubiran/talks

TypeScript types for the localized JSON files generated by [talks.soubiran.dev](https://talks.soubiran.dev).

`LocalizedTalkMetadata` describes one `meta.en.json` or `meta.fr.json` file. `LocalizedTalkCatalog` describes the matching `talks.en.json` or `talks.fr.json` catalog.

## Usage

Import `LocalizedTalkMetadata` for a per-talk metadata file, or `LocalizedTalkCatalog` for a localized catalog. Pass `en` or `fr` as the type parameter when the locale is known.
