Nuxt permet de réunir le frontend et le backend dans une même application. Cette présentation montre comment NuxtHub complète cette approche avec les services Cloudflare pour gérer une base de données, du stockage clé-valeur, des fichiers, des files d'attente et le déploiement.

La présentation parcourt aussi le module NuxtHub, ses commandes de déploiement et son tableau de bord d'administration. Le développement local et la production utilisent le même environnement applicatif.
