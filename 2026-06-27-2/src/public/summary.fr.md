Vite organise le traitement des modules dans une pipeline entre le projet et le navigateur. Cette présentation explique son serveur de développement, son bundler de production et son système de plugins à travers le CSS, les images, le JSX, les modules virtuels, les routes, les données et les informations de build générées.

Elle construit ensuite des plugins avec `resolveId`, `load` et `transform`, puis montre comment les hooks `config`, `configResolved`, `buildStart` et `buildEnd` permettent d'intervenir dans le cycle de vie de Vite.
