Ajouter une dépendance JavaScript est simple, mais le projet récupère aussi tout l'arbre qui l'accompagne. À partir de `is-string`, cette présentation montre comment identifier les paquets installés indirectement et repérer ceux qui peuvent être remplacés par du code natif ou une solution plus légère.

Elle présente plusieurs outils d'analyse ainsi qu'e18e, un projet qui travaille à améliorer l'écosystème JavaScript. L'objectif est de prendre le temps d'observer ses dépendances avant d'en ajouter une nouvelle.
