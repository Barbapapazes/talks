NuxtHub connects Nuxt’s full-stack development model with Cloudflare’s distributed platform. The talk starts with the needs of a production application, then introduces Cloudflare services for KV storage, SQL databases, blobs, queues, deployments, analytics, workflows, and coordination across the edge.

NuxtHub packages this infrastructure as a Nuxt module, CLI, and dashboard. Developers can use KV, D1, R2, and Queues locally and in production, create and deploy applications, inspect logs, manage data, and configure Git repositories or custom domains without changing application code.
