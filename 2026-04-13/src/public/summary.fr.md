Cette présentation explique la pipeline de Vite entre les fichiers du projet et le navigateur. Elle montre comment Vite transforme à la demande le CSS, les images, le JSX et les autres modules, puis comment il prépare le code pour la production.

Les plugins sont étudiés à travers leurs hooks de module et leurs hooks de cycle de vie. Les exemples couvrent la transformation de code, le chargement de Markdown externe, les modules virtuels, les routes générées, les données et icônes virtuelles, les informations de build, le HMR, les middlewares, les macros, Laravel Vite et Nitro.
