# How AI agents work

Presentation for [issue #148](https://github.com/Barbapapazes/talks/issues/148), part of [AI for Everyone](https://beta.soubiran.dev/ai-for-everyone).

English slides with French speaker notes and scripted, keyboard-driven demos. Presentation target: 15 minutes, followed by discussion and practical questions.

The deck moves from the agent definition and execution loop to four configurations, then compares them using the same bug-fixing task. The demos do not call a model or execute real tools.
